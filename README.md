Какие изменения были внесены:
  - Создан класс AppContext, для единого создания других компонент;
  - Рефакторинг Main: Убрано прямое создание экземпляров классов с помощью оператора new. Получение готовых сервисов переведено на обращения к единой точке входа — AppContext.getInstance().

Используемые фреймворки и библиотеки:
  - JUnit 5 (Jupiter): Для структуры тестов, аннотаций жизненного цикла (@BeforeEach, @AfterEach) и утверждений (assertAll, assertSame, assertNotSame, assertInstanceOf).
  - Mockito: Для изоляции сервисов при проведении изолированных модульных тестов.
